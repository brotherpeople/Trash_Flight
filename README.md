A classic 2D vertical shooter game built with Unity, featuring progressive difficulty, weapon upgrades, and boss battles.
*This project was created following 나도코딩 (nadocoding) Unity tutorial series.*

## Installation & Build

- Download the Trash_Flight.zip file from the releases section
- Extract the ZIP file to any location on your computer
- Run Trash_Flight.exe to start the game
- No installation required - the game runs as a standalone executable

## Core Mechanics

- **Movement**: Mouse-controlled horizontal movement
- **Auto-Shooting**: Automatic weapon firing
- **Weapon Upgrades**: Upgrade weapons every 20 coins collected
- **Progressive Difficulty**: Enemies get faster and stronger every 10 waves
- **Boss Battles**: Face powerful bosses after enemy waves
- **One-Hit Death**: Avoid all enemies to survive

## Game Controls

- **Mouse**: Move cursor to control player position
- **ESC**: Toggle pause during gameplay / Quit application when game over

## How to Play

1. **Move your character** with your mouse cursor
2. **Shoot automatically** - your character fires projectiles continuously
3. **Collect coins** from destroyed enemies to upgrade weapons (every 20 coins)
4. **Survive waves** of increasingly difficult enemies
5. **Defeat bosses** that appear after enemy cycles
6. **Avoid collision** with enemies - one hit means game over!

Press ESC to pause anytime or restart after game over.
